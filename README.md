# Atrium

Панель и редактор каталога сервисов домашней лаборатории. Flask-приложение, которое:

- показывает плитки сервисов с живыми статусами (точка: работает, нужен вход, недоступен);
- даёт добавлять, менять и удалять сервисы через веб-интерфейс;
- генерирует конфиг Caddy и поддерживает загрузку своих иконок;
- проверяет бэкенд и сертификат прямо из формы;
- позволяет поставить фон панели: один для всех.

Редактирование защищено паролем администратора (не меньше 9 знаков). Просмотр открыт всем, кто имеет доступ к панели.

Текущая версия: 1.0.0, список изменений в [CHANGELOG.md](CHANGELOG.md).

## Быстрый старт

```bash
podman build -t atrium .
mkdir -p data && cp services.example.yaml data/services.yaml && cp generate.py data/
podman run --rm -it -v "$PWD/data:/data:z" atrium flask set-password
podman run -d --name atrium -p 5000:5000 -v "$PWD/data:/data:z" \
  -e CADDY_IMPORT=/data/Caddyfile.apps atrium
```

Откройте `http://localhost:5000`. Для редактирования войдите с паролем администратора.

Подробности развёртывания: [deploy/README.md](deploy/README.md).

## Структура

- `app/` — приложение Flask, шаблоны и статика
- `generate.py` — генератор конфига Caddy из `services.yaml`
- `services.example.yaml` — пример каталога сервисов
- `deploy/` — примеры для systemd и инструкция по развёртыванию
- `CHANGELOG.md` — история версий

## Сервисы за прокси Caddy

У каждого сервиса три галочки, и они решают разные задачи:

- **Не проверять сертификат** — сервис на https с самоподписанным сертификатом. Caddy не станет проверять его сертификат.
- **Передавать адрес как есть (Host)** — Caddy передаёт сервису адрес панели (`Host`), а не адрес бэкенда. Нужна сервисам, которые проверяют свой Origin/Host (ошибка «origin invalid») или после входа уводят на свой адрес.
- **Закрыть входом через Caddy** — Caddy спрашивает логин перед открытием. Работает только если в контейнере Caddy заданы `PANEL_USER` и `PANEL_PASS_HASH`.

Пример для сервиса на https, который проверяет свой адрес: Backend `192.168.0.40:8889`, схема `https`, галочки «Не проверять сертификат» и «Передавать адрес как есть». Подробнее — в справке панели, раздел «Пример 3».

## Личные данные

В репозитории нет адресов, паролей и ключей, только примеры с условными адресами (`example.lan`, `192.168.0.x`). Файлы `services.yaml`, `admin.json`, `secret.key`, `settings.json`, `backgrounds/`, `icons/` и каталог Caddy с сертификатами создаются на сервере и в `.gitignore`.

## Требования

Python 3.11, Flask, PyYAML, requests, cryptography (см. `requirements.txt`). Для работы с Caddy нужен Caddy 2 с локальным центром сертификатов (`tls internal`).
