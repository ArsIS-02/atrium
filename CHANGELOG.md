# Changelog

## Не выпущено

- Цветные индикаторы доступности продублированы текстом, добавлена сводка по видимым сервисам с учётом поиска.
- Добавлены тесты классификации HTTP-статусов, проверки бэкенда, API и главной страницы.
- Поле `proxy: false` сохраняет сервис в каталоге, но больше не создаёт для него лишний маршрут Caddy.
- Поле `host` связывает сервис с хостом HostDeck. Для неотвечающего сервиса на разрешённо выключенном и действительно офлайн-хосте показывается нейтральный статус «Ожидаемо выключен».
- Интеграция включается переменными `HOSTDECK_URL` и `HOSTDECK_EXPORT_TOKEN`; токен передаётся заголовком. Ошибка HostDeck не мешает обычным HTTP-проверкам и не скрывает недоступность.
- Для неотвечающего сервиса с активным окном HostDeck добавлен статус «Обслуживание» с датой окончания и причиной в подсказке. Он имеет приоритет над ожидаемым выключением, но не меняет успешные HTTP-ответы и 401/403; истёкшее окно игнорируется.

## 1.0.0 — 2026-10-19

Первая публичная версия Atrium.

- Панель сервисов с живыми статусами: работает, нужен вход, недоступен.
- Добавление, изменение и удаление сервисов через веб-интерфейс.
- Генерация конфига Caddy из `services.yaml`, перезагрузка Caddy вручную.
- Вход администратора по паролю: не меньше 9 знаков, до 128, хранится только хеш, пять неверных попыток блокируют вход на 15 минут. Команда задания пароля: `flask set-password`.
- Проверка бэкенда и сертификата прямо из формы.
- Иконки из dashboard-icons и свои иконки (png, svg, webp).
- Фон панели один для всех, с регулируемым затемнением.
- Опции сервиса: «Не проверять сертификат», «Передавать адрес как есть (Host)», «Закрыть входом через Caddy».
- Справка со схемой работы, примерами и частыми ошибками.
