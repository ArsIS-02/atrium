# Changelog

## 1.0.0 — 2026-10-19

Первая публичная версия Atrium.

- Панель сервисов с живыми статусами: работает, нужен вход, недоступен.
- Добавление, изменение и удаление сервисов через веб-интерфейс.
- Генерация конфига Caddy из `services.yaml`, перезагрузка Caddy вручную.
- Вход администратора по паролю: не меньше 9 знаков, до 128, хранится только хеш, пять неверных попыток блокируют вход на 15 минут. Команда задания пароля: `flask set-password`.
- Проверка бэкенда и сертификата прямо из формы.
- Иконки из dashboard-icons и свои иконки (png, svg, webp).
- Фон панели один для всех, с регулируемым затемнением.
- Опции сервиса: «Не проверять сертификат», «Передавать адрес как есть (Host)», «Закрыть входом через Caddy».
- Справка со схемой работы, примерами и частыми ошибками.
